# Inertia documentation

## Using Inertia

- [Getting started](getting-started.md): install, choose a workspace folder,
  add a model provider, first chat, optional Docker.
- [Tools](tools.md): every tool an agent can call, and how permissions
  and modes work.
- [Agents and routines](agents-and-routines.md): agents, sub-agents and the
  crew, group conversations, skills, memory, scheduled routines.
- [Integrations](integrations.md): MCP servers, OpenAPI specs, Composio apps,
  lifecycle hooks.
- [Computers](computers.md): Docker, Daytona and local machines, the sandbox
  image, the live desktop.
- [The workspace folder](workspace.md): layout, file formats, backup and
  restore.
- [Security model](security.md): what is stored, what leaves your machine,
  what the permission system does and does not protect against.
